# Card gallery

Preview all **25 implemented templates**. Each image is a generated example; its caption identifies the card type and numeric template. Open an image to inspect the full PNG.

Create these cards with [EF_Cards](reference/client.md), or start with the [quickstart](getting-started/quickstart.md). Profile and character previews use public data; All Characters shows an authenticated owner's collection. Pulls and Wiki are not implemented.
